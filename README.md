# FootyDex

五大联赛 + 中超共 **112 支球队**的资料页：队徽、球场实拍、球员名单、队史荣誉与名宿、近 10 场战绩与未来赛程、赛季数据、联赛积分榜 / 球员榜 / 纪律榜、球队对比、赛程日历、新闻聚合。

**在线打开：<https://h1covo.github.io/footydex/>**

## 说明

- **单文件**：整个应用就是 `index.html`（约 5 MB），样式 / 脚本 / 数据 / 字体全部内嵌 —— 下载后双击本地打开也能正常使用，无需服务器、无构建步骤。
- **数据来源**：ESPN 公开 API（实时赛程 / 积分榜 / 榜单 / 球员）+ 本地离线快照（进站秒开，后台渐进同步）。
- **图片**：球场照片来自 Wikimedia Commons（自由授权，已逐张标注作者与协议）；队徽来自 ESPN CDN，版权归各俱乐部 / 联赛所有。
- **语言**：中文为主（大陆规范译名），右上角可切换英文。

> 演示用途，球队 / 球员 / 赛程数据请以官方信息为准。
